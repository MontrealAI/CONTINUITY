Choose a language

English and Français links appear at the top and bottom of every page. With JavaScript, switching languages preserves the section you are reading. On the paper page, it also preserves valid economic-illustration settings.

Without JavaScript, language links, PDFs, still previews and transcripts remain available. The economic illustration shows the paper’s starting case; its controls are disabled so they cannot display settings without updated results.

Navigation and accessibility

  • Use Tab to reach links and controls. The first link skips to the main content; keyboard focus is visible.
  • Adjust the economic illustration’s sliders with the arrow keys. Results and accessible values update in your selected language.
  • Gallery previews stay still until an explicit action. Only one animation plays at a time. Stop restores the still preview; leaving the page or hiding the tab also stops playback.
  • Every animation has alternative text and a complete transcript. Open the transcript using Enter or Space.
  • The system reduced-motion preference disables animated scrolling. Enabling this preference stops active animation; playing again requires an explicit action.

Open the library locally

From the root of your repository copy, start Python’s local file server:

python3 -m http.server 8000 --bind 127.0.0.1

Then open the English library on your computer. The server is limited to your computer. Stop it with Ctrl+C.

You can also open docs/research/index.html directly. Some browsers then limit the PDF preview or address updates. Serving the repository root keeps neighboring guides accessible; they may appear as raw Markdown.

Local pages, PDFs and media can be read without external services. GitHub links, original publications and related papers require Internet access.

Source language and provenance

The related Lab papers are in English and labeled accordingly. Bibliographic titles, publication URLs, software identifiers, hashes and historical data retain their original form. They are not translated into new commands or new results.

The French GIFs are generated conceptual adaptations, as explained in the gallery. A translation, media asset or repository copy adds no operational validation or independent certification.

The local library is not an announcement of a newly published website. Reader canonical references and citations continue to identify the original publications.
